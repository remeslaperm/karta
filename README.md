# Карта промыслов и ремесел Пермского края (Vue 3 + TypeScript)

Интерактивная карта точек с фильтром по категориям. Без бэкенда — все данные
читаются прямо из Excel-файла в браузере.

## Стек

- Vue 3 + `<script setup>` + TypeScript
- Vite
- Leaflet + Leaflet.markercluster (кластеризация точек при отдалении)
- SheetJS (`xlsx`) — чтение `.xlsx` прямо в браузере, без сервера

## Быстрый старт

```bash
npm install
npm run dev
```

Откроется адрес вида `http://localhost:5173`.

Сборка для продакшена (например, для выкладки на статический хостинг):

```bash
npm run build
npm run preview   # локально проверить собранную версию
```

Собранные файлы появятся в папке `dist/` — их можно разместить на любом
статическом хостинге (достаточно просто раздавать файлы, сервер с бэкендом не нужен).

## Автоматическая публикация на GitHub Pages

В проекте есть файл `.github/workflows/deploy.yml`. После каждой отправки
изменений в ветку `main` GitHub сам собирает сайт и выкладывает его на GitHub Pages —
собирать локально и загружать папку `dist/` не нужно.

Один раз в репозитории нужно включить: **Settings → Pages → Build and deployment →
Source: GitHub Actions**. Ход сборки виден на вкладке **Actions**.

## Структура данных

Файл с данными: `public/data/points.xlsx` (первый лист таблицы).
Ожидаемые столбцы — как в присланном примере:

| Столбец    | Назначение                                   |
|------------|-----------------------------------------------|
| ID         | Уникальный идентификатор точки, также имя папки с картинками |
| Заголовок  | Заголовок в описании точки (может быть пустым) |
| Описание   | Текст под заголовком                           |
| Категория  | Категория для фильтра                          |
| широта     | Широта (число)                                 |
| долгота    | Долгота (число)                                |

Чтобы обновить данные — просто замените `public/data/points.xlsx` новым файлом
с той же структурой столбцов и обновите страницу (перезапускать сборку не нужно
в режиме `npm run dev`; для продакшен-сборки — пересоберите проект командой `npm run build`,
если файл был изменён локально до сборки).

### Координаты в нестандартном формате

Если в ячейке широты/долготы встречается не просто число, а текст с несколькими
значениями (как в примере — несколько населённых пунктов в одной строке),
скрипт возьмёт первое найденное число, а в консоли браузера появится предупреждение.
Такие строки стоит проверить и, при необходимости, разбить на отдельные строки
в таблице — каждая точка на карте соответствует одной строке.

## Картинки для точек

Не у всех точек есть изображения — это нормально.

Картинки нужно класть в:

```
public/data/images/<ID>/картинка1.jpg
public/data/images/<ID>/картинка2.jpg
...
```

где `<ID>` — значение из столбца `ID` в таблице. Поддерживаются форматы:
`.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`.

Список картинок собирается автоматически перед запуском (`npm run dev`) и
сборкой (`npm run build`) скриптом `scripts/generate-images-manifest.mjs` —
он сканирует папку `public/data/images` и создаёт файл
`public/data/images-manifest.json`, который затем читает страница в браузере.
Это не сервер и не требует ручных действий — манифест просто пересчитывается
каждый раз при запуске команд `npm run dev` / `npm run build`. Если вы добавили
или убрали картинки во время работы `npm run dev`, перезапустите команду
(или выполните `npm run images:manifest` вручную и обновите страницу).

Если у точки несколько картинок, в её всплывающем окне на карте появится
галерея со стрелками «‹ ›» и счётчиком.

## Фильтр по категориям

Список категорий строится автоматически из столбца «Категория» — ничего
хардкодить не нужно. При открытии страницы выбраны все категории; в выпадающем
списке можно снять/поставить отметки у отдельных категорий или воспользоваться
ссылками «Выбрать все» / «Снять все».

## Точки на карте

- При достаточном отдалении близкие точки объединяются в кластер с числом
  точек внутри (Leaflet.markercluster).
- При клике на кластер карта приближается и кластер разбивается на отдельные
  точки (либо на более мелкие кластеры).
- При клике на точку открывается всплывающее окно с категорией, заголовком,
  описанием и (если есть) галереей изображений; повторный клик или клик вне
  окна — закрывает его.

## Структура проекта

```
├── public/
│   └── data/
│       ├── points.xlsx          # исходная таблица с точками
│       └── images/<ID>/...      # изображения по папкам с ID точки
├── scripts/
│   └── generate-images-manifest.mjs
├── src/
│   ├── components/
│   │   ├── CategoryFilter.vue   # селектор категорий (мультивыбор)
│   │   └── MapView.vue          # карта Leaflet + кластеризация + попапы
│   ├── composables/
│   │   └── usePointsData.ts     # чтение и разбор points.xlsx в браузере
│   ├── types/point.ts
│   ├── App.vue
│   ├── main.ts
│   └── style.css
└── vite.config.ts
```
